# Maaya Kids Castle, Annur

School portal: attendance, staff attendance, fees and reminders, homework and classwork, calendar, notices, admissions enquiries, parent logins, English and Tamil.

Live site: https://gkgokul600-byte.github.io/maaya-kids-castle/

Note: this static version saves data in each browser. To share data between staff and parents across devices, it needs a backend (for example Firebase or Supabase).
